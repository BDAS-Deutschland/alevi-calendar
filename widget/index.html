Alevitischer Kalender

Alle alevitischen Fasten-, Fest- und Gedenktage – zum Einbinden in jede Website, zum Abonnieren und zum Herunterladen. Auf Deutsch, Türkisch und Englisch.

1. Einbinden mit Script (WordPress & Co.)

In WordPress einen Block „Individuelles HTML“ einfügen und diesen Code hineinkopieren:

<script src="{{BASE_URL}}widget.js" defer></script>
<alevi-calendar lang="de"></alevi-calendar>

Optionen: lang="de|tr|en" (Standard: Sprache der Website), year="2027" (Standard: Jahr des nächsten Termins), target="_blank" (Links in neuem Tab).
Farben anpassen (optional): <alevi-calendar style="--alevi-accent:#cc2d1d; --alevi-text:#68686b">

2. Einbinden mit iframe (Wix, Squarespace, Jimdo …)

Für Baukästen, die keine Scripts erlauben:

<iframe src="{{BASE_URL}}embed?lang=de" title="Alevitischer Kalender"
        allow="clipboard-write" style="width:100%;height:1150px;border:0" loading="lazy"></iframe>

Optional: Höhe automatisch anpassen (wenn Scripts erlaubt sind) – dem iframe id="alevi-cal" geben und dazu:

<script>
addEventListener("message", function (e) {
  if (e.data && e.data.type === "alevi-calendar:height")
    document.getElementById("alevi-cal").style.height = e.data.height + "px";
});
</script>

3. Kalender abonnieren oder herunterladen

Abonnieren verbindet den eigenen Kalender mit diesem Feed – neue Termine erscheinen automatisch. Herunterladen importiert die Termine einmalig.

Deutsch{{BASE_URL}}abo-de
Türkçe{{BASE_URL}}abo-tr
English{{BASE_URL}}abo-en

Im Widget gibt es dafür die Buttons „Abonnieren“ und „Herunterladen“.

4. JSON-API

GET events.jsonAlle Termine mit Titeln und Hinweisen in DE/TR/EN, Kategorie, Link und iCal-Dateien.
GET abo-{de|tr|en}Kalender-Feed (iCalendar) pro Sprache.
GET events/{id}-{lang}.icsEinzelner Termin, z. B. events/2026-sivas-de.ics.
fetch("{{BASE_URL}}events.json")
  .then(r => r.json())
  .then(data => console.log(data.events));
